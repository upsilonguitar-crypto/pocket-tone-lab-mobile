# SONICLINK UI Edition

Cette édition reprend la grammaire graphique et les assets du SONICLINK V1.7.2 fourni par l'utilisateur, puis ajoute les fonctions Pocket Tone Lab sans modifier le firmware du Pocket Master.

## Écran principal
- chaîne NR / FX1 / DRV / AMP / IR / EQ / FX2 / DLY / RVB avec les assets ON/OFF du SONICLINK fourni ;
- un seul module édité à la fois, comme dans une interface multi-effets mobile ;
- potards basés sur l'asset `knob_bg.png` du SONICLINK fourni ;
- modèle, bypass, déplacement et paramètres dans le même panneau ;
- presets étendus accessibles par drawer, sans encombrer l'écran principal.

## Tone Match ajouté
- nouvel onglet dédié dans la même grammaire SONICLINK ;
- comparaison locale de deux extraits audio ;
- capture micro/entrée audio Android 8 secondes ;
- FFT + profil spectral + score de similarité ;
- corrections bornées avec A/B local ;
- aucune écriture matérielle automatique.

## Extensions conservées
- 301 presets / 46 artistes / 133 presets morceaux ;
- import/export natif `.prst` ;
- snapshots / setlists ;
- Tone DNA ;
- Performance Mode ;
- Tone Health ;
- BPM / delay calculator ;
- USB MIDI direct + Hardware Guard double verrou.

## Sécurité matérielle
Le changement d'interface ne modifie pas les garde-fous :
- connexion = lecture uniquement ;
- écriture temporaire armée explicitement ;
- sauvegarde permanente armée séparément ;
- aucune fonction firmware/reset/erase/bootloader n'est implémentée.
